# Безопасность TEGIN IT Courses

Дата проверки: 3 ноября 2026. Версия: v3 (сборка `build.py`, имена файлов с хешем содержимого).

В этом документе описано, что проверено, какие проблемы нашлись, что исправлено и какие ограничения остаются. Он не утверждает, что сайт абсолютно защищён. Это значит лишь, что перечисленные ниже проверки пройдены на момент сборки.

> **Қысқаша (қазақша).** Сайт статикалық: серверсіз, тіркеусіз және сыртқы скрипттерсіз. Тексерілгендер: XSS және DOM XSS, innerHTML, URL, eval, localStorage, сыртқы сілтемелер, Service Worker және CSP. Табылған 6 мәселе түзетілді. GitHub Pages HTTP-тақырыптарды баптауға мүмкіндік бермейді, сондықтан clickjacking пен HSTS-тен қорғаныс толық емес. Толығырақ — төменде, орыс тілінде.

## 1. Что из себя представляет сайт

- Статическая страница на GitHub Pages: HTML, один JS-бандл, один CSS-файл, скрипт ранней инициализации, шрифты, логотип, иконки и Service Worker.
- Нет сервера, аккаунтов, отправки форм, аналитики, рекламы и cookies.
- Во время работы сайт обращается только к своему домену. Внешние домены есть лишь в ссылках, по которым человек переходит сам: `github.com` (курсы) и `t.me` (связь с автором).
- Данные пользователя хранятся только в `localStorage` этого браузера и никуда не отправляются: прогресс по Roadmap, выбранный метод, «Мои курсы», статистика таймера, язык и тема.
- Секретных ключей, токенов и платных API в коде нет. Это проверено поиском по `src/` и `dist/` (`api_key`, `secret`, `token`, `bearer`, `sk-`, `ghp_`, `AIza`).

Что ещё сделано:
- Ссылки на GitHub собираются только из идентификатора, прошедшего регулярное выражение (`owner/repo`, `/tree|blob/…`, `topics/…`). Ссылка на Telegram берётся из `src/config.js` и проверяется по шаблону `https://t.me/<имя>`. Если проверка не пройдена, кнопки отключаются.
- `<meta name="referrer" content="strict-origin-when-cross-origin">`, у всех внешних ссылок `noreferrer`.
- Форма связи ничего не отправляет сама. Текст до 1000 символов копируется в буфер обмена только по нажатию кнопки, затем открывается Telegram. Сайт не видит, что человек напишет дальше.
- Регистрация Service Worker проходит через политику Trusted Types (`createScriptURL` пропускает только `sw.js`).

Функциональные ошибки, найденные тестами при проверке v3 и исправленные:
- после перезагрузки страницы запущенный таймер сбрасывался (сравнение `undefined` с `false` при проверке сохранённого состояния);
- при первом визите страница один раз перезагружалась, когда Service Worker брал её под контроль. Теперь перезагрузка бывает только после нажатия «Обновить».

## 4. Ограничения, которые остаются

GitHub Pages — статический хостинг, и HTTP-заголовки ответа на нём настроить нельзя. Поэтому:

1. **CSP работает только через `<meta>`.** В таком виде браузеры игнорируют директивы `frame-ancestors`, `report-uri` / `report-to` и `sandbox`. Отчёты о нарушениях собрать нельзя.
2. **Защиты от clickjacking нет.** Нельзя отправить `X-Frame-Options` или `frame-ancestors`, поэтому чужой сайт может встроить страницу во `<iframe>`. JS-«фреймбастинг» не добавлен: он обходится атрибутом `sandbox` и создал бы ложное ощущение защиты. Риск низкий: на сайте нет входа, платежей и действий от имени пользователя.
3. **HSTS, `X-Content-Type-Options`, `Permissions-Policy`** задать нельзя. Включите **Enforce HTTPS** в настройках Pages.
4. **Общий origin.** Сайт вида `https://<user>.github.io/<repo>/` делит origin со всеми Pages-сайтами этого аккаунта, и их скрипты могут читать и менять `localStorage` этого сайта. Здесь хранятся только несекретные данные (прогресс, расписание), и при чтении они проверяются. Для полной изоляции используйте отдельный аккаунт или организацию либо собственный домен.
5. **Trusted Types** гарантированно работают в браузерах на Chromium: Chrome, Edge, Samsung Internet, Opera. В остальных браузерах защита держится на экранирующем шаблоне и единственной точке записи HTML.
6. **`localStorage` не шифруется.** Человек с доступом к устройству может увидеть прогресс и расписание. Персональных данных сайт не хранит.
7. **Уведомления таймера** работают, только пока страница или установленное приложение открыты: push без сервера невозможен. Для напоминаний есть экспорт `.ics` в календарь.
8. **Содержимое курсов** — сторонние репозитории на GitHub. Их безопасность и актуальность от сайта не зависят. Все ссылки проверены 2 ноября 2026 через `git ls-remote`; перенесённые и пустые репозитории заменены или помечены в Roadmap.
9. **Бандл не минифицирован** — осознанно, чтобы код можно было проверить. На безопасность это не влияет.

## 5. Рекомендации

- В настройках репозитория включите **Settings → Pages → Enforce HTTPS**.
- Если нужен полный набор заголовков, подключите свой домен через CDN, который умеет их задавать, и выставьте: `Content-Security-Policy` (та же политика + `frame-ancestors 'none'`), `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy: camera=(), microphone=(), geolocation=()`, `Strict-Transport-Security: max-age=31536000`.
- Не добавляйте скрипты с CDN без закреплённой версии и атрибута `integrity` (SRI). Если всё же добавляете, внесите домен в CSP.
- Перед каждым выпуском запускайте `python3 build.py`, затем `npm run lint` и `npm run roadmaps` в папке `tests` и `python3 tests/e2e.py`.
- Контакт в Telegram меняется в одном месте: `src/config.js` → `telegram`.
